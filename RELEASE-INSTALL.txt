AI Math Tutor – v2.6.2-beta.1

1. Giải nén chép đè vào:
   C:\AI_Project\ai-math-tutor-7

2. Chạy:
   npm run build

3. Nếu build OK:
   npm run dev

4. Kích hoạt Cloud thật:
   - Supabase SQL Editor: chạy docs\cloud\supabase-pilot-schema.sql
   - copy .env.example -> .env.local
   - điền SUPABASE_URL, SUPABASE_SECRET_KEY, PILOT_TEACHER_KEY
   - restart npm run dev

5. Kiểm tra:
   http://localhost:3000/cloud-activation
   http://localhost:3000/teacher-cloud
   http://localhost:3000/cloud-sync

6. Chỉ khi /cloud-activation hiện 3 READY mới đưa học sinh Pilot lên Cloud.
