AI Math Tutor – v2.2.0-beta.1

1. Giải nén và chép đè toàn bộ vào:
   C:\AI_Project\ai-math-tutor-7

2. Không cần npm install.

3. Chạy build trước:
   npm run build

4. Nếu build thành công:
   npm run dev

5. Mở:
   http://localhost:3000/teacher

6. Kiểm thử:
   - Overview
   - Students
   - Skills
   - Mistakes
   - Student Detail
   - Export CSV
   - In / Lưu PDF

Release này không thêm package npm mới.
