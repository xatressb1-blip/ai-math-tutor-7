# Phase 1.3 – Foundation UI

Thay 3 file trong project bằng các file tương ứng trong gói này:

- app/page.tsx
- app/globals.css
- app/layout.tsx

Sau đó chạy:

npm run dev

Mở:
http://localhost:3000

Kiểm thử:
1. Trang hiển thị tiêu đề "AI Math Tutor 1:1 – Toán lớp 7".
2. Có khu vực năng lực mẫu với 4 kỹ năng.
3. Có 4 thẻ năng lực cốt lõi.
4. Có Learning Loop 6 bước.
5. Kiểm tra trên trình duyệt desktop và thu nhỏ cửa sổ để xác nhận giao diện responsive.

Cuối cùng dừng dev server và chạy:

npm run build

Phase 1.3 chỉ được coi là hoàn thành khi build thành công.
