# Release v0.3.0-alpha.1 — Lesson Engine Foundation

## Mục tiêu
Biến trang Student Brain tĩnh thành một Lesson Player tương tác cho Demo Alpha.

## Chức năng mới
- Lesson Definition chuẩn hóa, tách nội dung khỏi giao diện.
- Lesson Repository và Lesson Engine.
- Lesson Player tương tác.
- Progress bar và ước lượng thời gian còn lại.
- 4 checkpoint trắc nghiệm trong Bài 1.
- Teaching rule: sai lần đầu nhận hint, sai tiếp nhận hint cụ thể hơn; không đưa đáp án ngay.
- Màn hình tổng kết buổi học.

## Phạm vi cố ý chưa làm
- Chưa gọi API AI thật.
- Chưa lưu kết quả vào database.
- Chưa cập nhật Student Brain sau reload.
- Chưa đăng nhập.

Các phần trên sẽ được nối ở Increment tiếp theo sau khi Lesson Player được nghiệm thu.

## Kiểm thử
1. `npm run dev`
2. Mở `http://localhost:3000`
3. Đi qua toàn bộ 11 bước của Bài 1.
4. Với một câu hỏi, cố tình chọn sai để kiểm tra hint.
5. Chọn đúng để mở nút Tiếp tục.
6. Hoàn thành bài và xem màn hình kết quả.
7. Dừng dev server và chạy `npm run build`.
