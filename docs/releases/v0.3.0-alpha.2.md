# Release v0.3.0-alpha.2 — AI Teaching Session

## Mục tiêu
Biến Lesson Player từ cơ chế đúng/sai đơn giản thành một Teaching Session có tín hiệu sư phạm.

## Thay đổi chính
- Thêm Teaching Session Engine.
- Adaptive Feedback theo số lần thử.
- Theo dõi thời gian phản hồi từng câu.
- Tính Confidence Score cho mỗi lượt trả lời đúng.
- Tổng hợp Confidence toàn buổi.
- Phân tích theo kỹ năng.
- Tách điểm mạnh và kỹ năng cần ôn.
- Hiển thị số câu đúng ngay lần đầu và thời gian học thực tế.

## Chưa có trong release này
- Chưa lưu Student Brain vào localStorage/database.
- Chưa gọi Gemini/OpenAI API.
- Chưa sinh câu hỏi động.

Đây là chủ đích. Release alpha.3 sẽ đồng bộ Teaching Session Summary vào Student Brain.

## Kiểm thử
1. npm run dev
2. Mở http://localhost:3000
3. Trả lời đúng ngay ít nhất một câu.
4. Cố tình trả lời sai một câu ít nhất 2 lần để kiểm tra hai tầng gợi ý.
5. Hoàn thành bài.
6. Kiểm tra màn hình tổng kết có Điểm, Confidence, Đúng lần đầu, Thời gian, Điểm mạnh/Cần ôn.
7. Ctrl+C
8. npm run build
