# v0.3.0-alpha.5 – Demo Alpha Candidate

## Mục tiêu
Biến chuỗi engine kỹ thuật thành một bản Demo có thể đưa cho nhóm học sinh đầu tiên trải nghiệm.

## Thay đổi chính
- Thêm màn hình chào trước buổi học, giảm cảm giác "phần mềm kỹ thuật".
- Thêm Learning DNA bản đầu, chỉ dựa trên dữ liệu quan sát được: tốc độ phản hồi, đúng lần đầu, confidence và số lần thử.
- Learning DNA được lưu vào localStorage và tích lũy qua nhiều buổi.
- Thêm lời nhắn Mentor cuối buổi theo kết quả thực tế.
- Thêm phiếu phản hồi Demo 20 giây: mức dễ hiểu và ý định học tiếp Bài 2.
- Giữ nguyên Lesson Engine, Adaptive Exercise và Student Brain Sync của alpha.4.

## Tiêu chí nghiệm thu
1. Mở trang thấy màn hình chào Demo Alpha Candidate.
2. Bấm Bắt đầu buổi học mới vào Lesson Player.
3. Hoàn thành Lesson + Adaptive Practice.
4. Cuối buổi thấy Student Brain, Learning DNA và phiếu phản hồi.
5. Reload trang: Student Brain và Learning DNA vẫn được nhớ.
6. `npm run build` thành công.
