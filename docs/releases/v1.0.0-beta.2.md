# v1.0.0-beta.2 – Lesson Authoring Studio

## Mục tiêu
Biến Lesson Definition từ dữ liệu chỉ dành cho lập trình viên thành nội dung có thể biên soạn và kiểm tra trực tiếp trên trình duyệt.

## Tính năng
- Route mới: `/authoring`
- Chỉnh metadata bài học.
- Chỉnh danh sách mục tiêu.
- Chỉnh Teaching Action, tiêu đề, nội dung và thời lượng từng bước.
- Xem preview câu hỏi của bước QUESTION.
- JSON Editor để chỉnh toàn bộ Lesson Definition, gồm question, hints và diagnostics.
- Lesson Validator kiểm tra lỗi/cảnh báo cấu trúc.
- Lưu bản nháp bằng localStorage.
- Xuất Lesson Definition thành file `.json`.
- Khôi phục Lesson 1 mẫu.
- Link Authoring Studio xuất hiện trên trang Demo.

## Không thay đổi
- Teaching Brain Beta 1.1.
- Student Brain Sync.
- Learning DNA.
- Adaptive Exercise.
- Demo Feedback.
- Cấu trúc Lesson Player hiện tại.

## Kiểm thử
1. `npm run dev`
2. Mở `http://localhost:3000`
3. Kiểm tra Demo học vẫn hoạt động.
4. Bấm `Authoring Studio`.
5. Đổi tên bài hoặc nội dung một Teaching Step.
6. Bấm `Lưu bản nháp`, F5 và xác nhận nội dung được khôi phục.
7. Sửa JSON rồi bấm `Áp dụng JSON`.
8. Bấm `Xuất JSON` và xác nhận trình duyệt tải file lesson JSON.
9. `npm run build`

## Ghi chú
Beta 1.2 chưa ghi file JSON trực tiếp vào source code của project. Trình duyệt không được phép tùy ý sửa file local trên ổ đĩa. Studio xuất JSON để Product Owner/Content Editor kiểm duyệt trước; Beta sau sẽ xây quy trình import/publish vào Content Repository.
