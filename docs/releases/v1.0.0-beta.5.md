# v1.0.0-beta.5 – Adaptive Exercise Banks & Learning Path

## Mục tiêu
Bật Adaptive Practice cho Bài 2–4 và kết nối các bài thành một lộ trình học nối tiếp có điều kiện.

## Tính năng
- Adaptive Exercise Bank riêng cho Bài 2, Bài 3, Bài 4.
- Mỗi bank có câu Củng cố / Vừa sức / Thử thách theo kỹ năng.
- AdaptivePractice nhận bank theo lesson thay vì hard-code Bài 1.
- Registry quản lý Exercise Bank theo lessonId.
- Learning Path Engine quyết định:
  - ADVANCE: đủ điểm + Confidence để sang bài tiếp theo.
  - REVIEW_CURRENT: cần củng cố trước.
  - COMPLETE_CHAPTER: đã tới cuối nội dung hiện có.
- Màn tổng kết hiển thị đề xuất lộ trình và nút học bài tiếp theo.
- Student Brain tiếp tục đồng bộ kết quả adaptive của tất cả Bài 1–4.
- Trang Library hiển thị badge Adaptive Ready.

## Ngưỡng Beta hiện tại
- Score >= 70
- Confidence >= 55
- Không quá 1 kỹ năng nằm trong reviewSkills

Các ngưỡng này là cấu hình Beta để kiểm thử, chưa phải chuẩn sư phạm cuối cùng.

## Kiểm thử
1. Chạy `npm run dev`.
2. Mở lần lượt Bài 2–4 và hoàn thành Teaching Flow.
3. Xác nhận mỗi bài chuyển sang 4 câu Adaptive Practice.
4. Làm tốt để quan sát độ khó tăng.
5. Cố tình sai nhiều để quan sát độ khó giảm.
6. Ở màn tổng kết:
   - kết quả tốt => đề xuất Bài tiếp theo;
   - kết quả chưa chắc => đề xuất ôn lại.
7. Xác nhận Student Brain ghi thêm session và skill tương ứng.
8. Chạy `npm run build`.
