# v1.0.0-beta.6 – Chapter 1 Learning Path Dashboard

## Mục tiêu
Cho học sinh nhìn thấy mình đang ở đâu trong Chương 1 và khóa/mở bài theo dữ liệu học tập đã lưu trong Student Brain.

## Tính năng
- Route mới: `/progress`
- Dashboard tiến độ Chương 1.
- Trạng thái bài học:
  - LOCKED
  - AVAILABLE
  - IN_PROGRESS
  - NEEDS_REVIEW
  - COMPLETED
- Tính tiến độ tổng thể của chương.
- Hiển thị Accuracy, Confidence và Mastery theo từng bài.
- Bài sau chỉ mở khi bài trước đạt ngưỡng hoàn thành Beta.
- AI Recommendation ưu tiên:
  1. bài cần ôn;
  2. bài đang học;
  3. bài mới đã mở.
- Review Queue lấy từ Mistake Memory.
- Hiển thị nhóm kỹ năng Mastery thấp nhất từ Student Brain.
- Thêm link Tiến độ tại Library và màn học.

## Ngưỡng Beta
Một bài được xem là COMPLETED khi:
- Accuracy >= 70%;
- Confidence >= 55 nếu có dữ liệu;
- Mastery trung bình >= 55 nếu đã có dữ liệu.

Ngưỡng này dùng để kiểm thử kiến trúc, chưa phải chuẩn đánh giá cuối cùng.

## Kiểm thử
1. `npm run dev`
2. Mở `/progress`.
3. Với Student Brain mới:
   - Bài 1 phải sẵn sàng;
   - các bài sau khóa theo lộ trình.
4. Học Bài 1 đạt kết quả tốt.
5. Quay lại `/progress`, xác nhận:
   - Bài 1 COMPLETED;
   - Bài 2 AVAILABLE.
6. Học Bài 2 cố tình sai nhiều.
7. Quay lại `/progress`, xác nhận Bài 2 NEEDS_REVIEW hoặc IN_PROGRESS và Bài 3 vẫn khóa.
8. Ôn lại Bài 2 đạt kết quả tốt để mở Bài 3.
9. `npm run build`.
