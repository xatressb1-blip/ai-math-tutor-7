# v1.0.0-beta.7 – Diagnostic Entry Test & Personalized Starting Point

## Mục tiêu
Không mặc định mọi học sinh bắt đầu từ Bài 1. Hệ thống đánh giá nhanh kiến thức tiền đề và 4 bài đầu Chương 1, sau đó chọn điểm bắt đầu cá nhân hóa.

## Tính năng
- Route mới: `/diagnostic`.
- 15 câu Diagnostic gồm:
  - 3 câu kiến thức tiền đề lớp dưới;
  - 3 câu Bài 1;
  - 3 câu Bài 2;
  - 3 câu Bài 3;
  - 3 câu Bài 4.
- Câu hỏi trong từng nhóm được sắp thứ tự thích ứng theo kết quả trước đó.
- Tính Score + Confidence theo từng bài.
- Personalized Starting Point: Bài 1, 2, 3 hoặc 4.
- Trường hợp kiến thức tiền đề yếu được gắn `PRE_CHAPTER_REVIEW` và bắt đầu từ Bài 1 với khuyến nghị củng cố nền tảng.
- Diagnostic History được lưu vào Student Brain.
- Diagnostic History riêng được lưu trong localStorage, tối đa 10 lượt gần nhất.
- Kết quả Diagnostic cập nhật tín hiệu Mastery/Confidence ban đầu cho Student Brain.
- Library hiển thị trạng thái Diagnostic và badge `YOU START HERE`.
- `/progress` yêu cầu Diagnostic trước khi mở Learning Path.
- Learning Path hỗ trợ trạng thái `PLACED_AHEAD`: các bài trước điểm bắt đầu được đánh dấu “Vượt qua đầu vào”, không giả vờ có session học.

## Quy tắc Starting Point Beta
- Kiến thức tiền đề < 50 → PRE_CHAPTER_REVIEW, bắt đầu Bài 1.
- Bài 1 < 65 → Bài 1.
- Bài 1 đạt, Bài 2 < 65 → Bài 2.
- Bài 1–2 đạt, Bài 3 < 65 → Bài 3.
- Bài 1–3 đạt → Bài 4.

Các ngưỡng trên chỉ là cấu hình Beta để kiểm thử. Chưa coi là chuẩn đánh giá sư phạm cuối cùng.

## Kiểm thử
1. Chạy `npm run dev`.
2. Mở `/diagnostic`.
3. Hoàn thành đủ 15 câu.
4. Kiểm tra màn hình kết quả có Score, Confidence và Bài bắt đầu.
5. Về `/`:
   - banner phải hiện `Diagnostic Completed`;
   - card bài bắt đầu phải có `YOU START HERE`.
6. Mở `/progress`:
   - các bài trước Starting Point phải là `Vượt qua đầu vào` nếu chưa có session thật;
   - Starting Lesson phải được mở;
   - bài sau vẫn khóa theo Learning Path.
7. F5 và xác nhận Diagnostic vẫn còn.
8. Làm lại Diagnostic và xác nhận Student Brain có lịch sử Diagnostic mới.
9. Chạy `npm run build`.
