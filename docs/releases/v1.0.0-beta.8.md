# v1.0.0-beta.8 – AI Personal Tutor Conversation

## Mục tiêu
Tạo trải nghiệm hỏi đáp 1:1 theo từng bài học, sử dụng Lesson Context và Student Brain thay vì một chatbot tổng quát.

## Tính năng
- `/tutor/[lessonId]`
- Conversation history theo lessonId.
- Tutor context lấy từ Mastery, Confidence và Mistake Memory.
- Tutor intents: Explain, Hint, Example, Rule, Check Understanding, Motivation.
- Teaching policy: ưu tiên gợi mở, không đưa đáp án ngay khi học sinh xin trợ giúp.
- Suggested questions.
- Voice input khi browser có Web Speech API.
- Text-to-speech cho phản hồi gần nhất.
- `/api/tutor` là abstraction boundary cho provider AI.

## Lưu ý kiến trúc
Beta 1.8 dùng Local Teaching Brain để release chạy ngay mà không cần API key. Đây là chủ đích để kiểm thử UX, conversation contract và Student Brain integration trước khi thêm cloud LLM.

## Kiểm thử
1. `npm run dev`
2. Mở `/` và bấm `Hỏi AI` ở Bài 1.
3. Hỏi: `Em chưa hiểu số đối là gì`.
4. Hỏi: `Cho em gợi ý`.
5. Hỏi: `Hỏi em một câu để kiểm tra`.
6. F5 và xác nhận lịch sử chat còn giữ.
7. Kiểm tra Bài 2 có lịch sử riêng.
8. Nếu Chrome/Edge hỗ trợ, thử nút microphone.
9. Thử `Nghe` để đọc phản hồi Tutor.
10. `npm run build`.
