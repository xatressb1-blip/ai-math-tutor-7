# v2.0.0-beta.1 – AI Reasoning Engine

## Mục tiêu
Đánh giá cách học sinh đi đến đáp án, không chỉ chấm kết quả cuối.

## Route mới
- `/reasoning/lesson-player-01`
- `/reasoning/lesson-player-02`
- `/reasoning/lesson-player-03`
- `/reasoning/lesson-player-04`

## Luồng
1. AI đưa một bài toán và chia thành các bước suy luận.
2. Học sinh nhập bước đang làm.
3. Reasoning Engine kiểm tra key idea và misconception patterns.
4. Sai lần 1: hint nhẹ.
5. Sai lần 2: hint cụ thể hơn.
6. Sai nhiều: explanation ngắn để tránh bế tắc.
7. Hoàn thành: Reasoning Score + Persistence Score được lưu vào Student Brain.

## Kiểm thử
- Bài 1: thử nhập `-6/12` ở bước quy đồng để xem lỗi tính toán.
- Bài 2: thử nhập `7/12` để xem chẩn đoán mất dấu âm.
- Bài 3: thử nhập `2^14` ở bước phép chia để xem lỗi quy tắc số mũ.
- Bài 4: thử nhập `x = 2` ở bước chuyển vế để xem chẩn đoán đổi dấu.
- Sau khi hoàn thành, mở `/progress` và kiểm tra Student Brain có session mới.
- Chạy `npm run build`.
