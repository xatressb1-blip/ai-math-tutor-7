# v2.1.0-beta.1 – Step-by-Step Solution Analyzer

## Mục tiêu
Nâng AI Reasoning Engine từ kiểm tra từng bước cơ bản thành một bộ phân tích lời giải có thể xác định bước sai đầu tiên, đo mức phụ thuộc gợi ý và khả năng tự sửa lỗi.

## Tính năng mới
- Route chuẩn mới: `/reasoning-lab/[lessonId]`
- Route cũ `/reasoning/[lessonId]` vẫn được giữ để tương thích.
- First Error Detection: đánh dấu bước sai đầu tiên.
- Hint Ladder 3 tầng.
- Step Map hiển thị trạng thái từng bước.
- Reasoning Analytics: Reasoning Score, First Attempt Accuracy, Hint Dependency, Error Recovery, Persistence, Misconception Count.
- Student Brain Sync dùng thêm First Attempt, Hint Dependency và Recovery.
- Learning History ghi đủ các chỉ số Reasoning mới.
- Không thêm package npm mới.

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Mở `/reasoning-lab/lesson-player-01`.
4. Cố tình nhập `-6/12` ở Bước 1.
5. Xác nhận First Error Detection chỉ đúng Bước 1.
6. Tiếp tục sai 2–3 lần để xem Hint 1 → Hint 2 → Hint 3.
7. Tự sửa đúng rồi hoàn thành toàn bộ lời giải.
8. Màn tổng kết phải có Reasoning / Đúng lần đầu / Phụ thuộc Hint / Tự sửa lỗi.
9. Mở `/progress` và kiểm tra Student Brain có session mới.
10. Kiểm thử Bài 2–4.
