# v2.2.0-beta.1 – Teacher Dashboard & Class Analytics

## Mục tiêu
Tạo bản demo dành cho giáo viên, tổng hợp dữ liệu học tập thành góc nhìn theo lớp và xác định học sinh cần hỗ trợ.

## Route
- `/teacher`

## Tính năng
- Tổng quan lớp 7A.
- Mastery / Confidence / Accuracy / Reasoning trung bình.
- Danh sách học sinh theo mức ưu tiên hỗ trợ.
- Skill Heatmap.
- Class Mistake Memory.
- Student Detail Drawer.
- CSV Export.
- In / Lưu PDF qua trình duyệt.
- Dữ liệu của học sinh đang dùng ứng dụng được đọc trực tiếp từ Student Brain localStorage.
- 5 học sinh còn lại là dữ liệu Demo để kiểm thử giao diện nhiều học sinh.

## Lưu ý kiến trúc
Beta 2.2 chưa có database đa người dùng. Teacher Dashboard dùng mô hình hybrid:
1. 1 học sinh LIVE = Student Brain hiện tại trên trình duyệt.
2. 5 học sinh DEMO = dữ liệu mô phỏng có cấu trúc tương thích.

Việc này cho phép kiểm thử UX và analytics trước khi xây Authentication + Cloud Database ở Production Sprint.

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Mở `http://localhost:3000/teacher`
4. Kiểm tra có 6 học sinh.
5. Học thêm một buổi ở Student App rồi quay lại `/teacher`.
6. Dòng `Học sinh Demo` có nhãn LIVE phải phản ánh dữ liệu mới.
7. Chuyển các tab Students / Skills / Mistakes.
8. Bấm một học sinh để mở Student Detail.
9. Bấm Xuất CSV.
10. Bấm In / Lưu PDF.
