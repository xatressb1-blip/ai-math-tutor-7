# v2.3.1-beta.1 – Knowledge Engine Foundation + Academic Schema

## Mục tiêu
Tạo một nguồn dữ liệu học thuật thống nhất để các engine hiện có dùng chung thay vì mỗi tính năng tự hiểu nội dung theo một cách khác nhau.

## Nguồn chuẩn
- PRIMARY: SGK Toán 7 Tập 1 KNTT.
- PRACTICE: SBT Toán 7 Tập 1 KNTT.
- ENRICHMENT: Tài liệu học tập Toán 7 KNTT.
- ADVANCED_ONLY: Chuyên đề nâng cao, chỉ mở sau khi đạt mastery.

## Academic Schema v1.0
Mỗi Academic Lesson có:
- Objectives + Bloom + mastery threshold.
- Concepts + prerequisites + representations.
- Vocabulary.
- AI Teaching Script theo phase.
- Worked Example Blueprint.
- Misconception Library.
- Hint Ladder.
- Reasoning Template.
- Practice Blueprint.
- Assessment Blueprint.
- Student Brain Mapping.
- Teacher Analytics Tags.
- Source References.
- Academic Quality Status.

## Foundation Chương II
Đã dựng nền học thuật cho đúng ba bài của Chương II – Số thực:
- Bài 5. Làm quen với số thập phân vô hạn tuần hoàn.
- Bài 6. Số vô tỉ. Căn bậc hai số học.
- Bài 7. Tập hợp các số thực.

Beta này chưa thay thế Lesson Player hiện hành bằng nội dung Chương II. Mục tiêu là khóa schema và academic governance trước; Beta 2.3.2 sẽ đưa nội dung hoàn chỉnh vào Lesson Player/Adaptive/Reasoning.

## Route mới
- `/knowledge-engine`

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Mở `/knowledge-engine`.
4. Xác nhận có 3 Academic Lesson Chương II và tất cả hiện `SCHEMA OK`.
5. Xác nhận Source Registry có SGK / SBT / tài liệu học tập / nâng cao.
6. Mở `/`, `/teacher`, `/progress`, các bài 1-4 để xác nhận chức năng Beta 2.2 không bị phá.
