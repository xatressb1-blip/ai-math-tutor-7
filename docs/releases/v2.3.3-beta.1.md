## Lưu ý baseline
ZIP đầu vào hiện có version `2.3.1-beta.1`, chưa có Lesson Player Bài 5–7.
Vì vậy release này đồng thời kích hoạt Bài 5–7 để giữ mạch nội dung Chương II → III liên tục.

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Mở trang chủ: phải có 11 bài, nhóm thành 3 chương.
4. Học thử Bài 8 → Adaptive Practice.
5. Mở Reasoning Bài 8 và hoàn thành.
6. Thử Bài 9, 10, 11.
7. Mở `/geometry-lab`, đổi 4 chế độ và kéo thanh góc.
8. Mở `/knowledge-engine`: phải có Chương II + Chương III và các bài SCHEMA OK.
9. Mở `/teacher`: kiểm tra session học mới vẫn được tổng hợp.
