# AI Math Tutor v2.4.0-beta.1 – Semester I Mastery & Pilot Analytics

## Mục tiêu
Chuyển hệ thống từ học theo bài sang giai đoạn ôn tập học kỳ I và đo dữ liệu Pilot.

## Tính năng
- `/mastery`: AI Revision Coach.
- Readiness Score.
- Kỹ năng yếu / kỹ năng mạnh.
- Kế hoạch ôn ưu tiên.
- `/mock-test`: đề mô phỏng học kỳ I.
- Chấm điểm theo chương.
- Ghi nhận lỗi theo kỹ năng.
- `/pilot`: Pilot Analytics.
- Lịch sử Mock Test localStorage.

## Lưu ý
Release này chưa có database nhiều học sinh. Pilot Analytics chỉ phản ánh Student Brain
và Mock Test của trình duyệt hiện tại.

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Mở `/mastery`.
4. Mở `/mock-test`, làm đủ câu và nộp bài.
5. Xác nhận điểm tổng và breakdown theo chương.
6. Mở `/pilot` và kiểm tra số Mock Test tăng.
7. Quay về trang chủ và kiểm tra ba nút mới.
