# AI Math Tutor v2.5.0-beta.1 – Pilot Student Experience

## Route mới
- `/student` – Student Home 2.0
- `/reflection` – End-of-session Reflection
- `/pilot-feedback` – Pilot Feedback
- `/teacher-pilot` – Teacher Pilot View

## Mục tiêu
Kiểm chứng trải nghiệm học sinh trước khi chuyển sang Multi-Student Cloud.

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Mở `/student`, kiểm tra Daily Mission.
4. Bấm ghi nhận hoàn thành phiên hôm nay.
5. Mở `/reflection`, lưu phản hồi.
6. Mở `/pilot-feedback`, gửi phản hồi.
7. Mở `/teacher-pilot`, xác nhận dữ liệu vừa xuất hiện.
8. Kiểm tra trên mobile/DevTools.
