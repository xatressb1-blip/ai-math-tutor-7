# AI Math Tutor v2.6.0-beta.1 – Multi-Student Pilot & Cloud Data Foundation

## Mục tiêu
Tạo nền tảng dữ liệu nhiều học sinh mà không phá Student Brain hiện có.

## Route mới
- `/pilot-roster` – tạo/chọn hồ sơ Pilot, giới hạn 10 học sinh.
- `/teacher-multi` – bảng tổng hợp lớp nhiều học sinh.

## Kiến trúc
- `MultiStudentWorkspace` schema v1.
- `brains: Record<studentId, StudentBrainSnapshot>`.
- `StudentDataProvider` tách UI khỏi cơ chế lưu trữ.
- `CloudStudentRepository` là contract cho database adapter ở bước sau.
- Bản beta.1 vẫn dùng localStorage và không gửi dữ liệu học sinh lên cloud.

## Migration
Lần đầu mở Pilot Roster, Student Brain local hiện tại được đưa vào workspace làm hồ sơ đầu tiên.

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Mở `/pilot-roster`.
4. Xác nhận hồ sơ hiện tại xuất hiện.
5. Tạo 2–3 học sinh Pilot.
6. Chọn qua lại các hồ sơ.
7. Mở `/teacher-multi`, xác nhận danh sách và chỉ số.
8. Refresh trình duyệt, xác nhận roster vẫn còn.
