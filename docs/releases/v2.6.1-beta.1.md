# AI Math Tutor v2.6.1-beta.1 – Cloud Pilot Data & Student Identity

## Mục tiêu
Cho phép Pilot nhiều thiết bị dùng Student Brain tập trung mà không phá localStorage hiện tại.

## Kiến trúc
- Browser không nhận Supabase Secret key.
- `/api/pilot-cloud` chạy server-side và gọi Supabase Data REST API.
- Ưu tiên `SUPABASE_SECRET_KEY` (sb_secret_...). Có fallback legacy `SUPABASE_SERVICE_ROLE_KEY`.
- Học sinh dùng `classCode + accessCode` để pull/push đúng hồ sơ.
- Giáo viên dùng `PILOT_TEACHER_KEY` để tạo/list hồ sơ Cloud trong Pilot.

## Route mới
- `/cloud-sync`
- `/teacher-cloud`
- `/api/pilot-cloud`

## Cấu hình Supabase
1. Tạo một Supabase project.
2. Mở SQL Editor và chạy `docs/cloud/supabase-pilot-schema.sql`.
3. Lấy Project URL và Secret key.
4. Tạo `.env.local` từ `.env.example`.
5. Điền `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `PILOT_TEACHER_KEY`.
6. Restart `npm run dev`.

## Vercel
Thêm cùng ba biến môi trường vào Project Settings > Environment Variables rồi Redeploy.

## Bảo mật Pilot
- Không dùng biến `NEXT_PUBLIC_` cho Secret key.
- Secret key chỉ được đọc trong Route Handler server-side.
- Bảng bật RLS và không tạo public policy.
- `PILOT_TEACHER_KEY` chỉ là lớp bảo vệ Pilot tạm thời, chưa thay thế hệ thống Auth production.

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Kiểm tra `/api/pilot-cloud` trả `configured: false` khi chưa có env; app local vẫn chạy.
4. Cấu hình Supabase + env, restart dev.
5. Mở `/teacher-cloud`, nhập Teacher Key, đưa 1 hồ sơ lên Cloud và ghi lại mã học sinh.
6. Mở trình duyệt khác/incognito, vào `/cloud-sync`, nhập mã lớp + mã học sinh, bấm tải Cloud.
7. Kiểm tra Student Brain đúng tên học sinh.
8. Học một phiên, quay lại `/cloud-sync`, bấm gửi tiến độ lên Cloud.
9. Giáo viên refresh `/teacher-cloud`, xác nhận sessions/skills cập nhật.
