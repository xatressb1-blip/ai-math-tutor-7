# AI Math Tutor v2.6.2-beta.1 – Supabase Pilot Cloud Activation

## Mục tiêu
Kích hoạt end-to-end Cloud Pilot trên Supabase mà không đưa Secret key xuống browser.

## Route
- `/cloud-activation` – health check 3 lớp.
- `/teacher-cloud` – đưa roster lên Cloud / kích hoạt toàn bộ.
- `/cloud-sync` – học sinh pull/push Student Brain.

## Security
- Supabase Secret key chỉ đọc ở Next.js server route.
- Mã học sinh lưu dưới SHA-256 theo `classCode:accessCode`, database chỉ giữ 4 ký tự cuối để nhận diện.
- RLS bật, không có public policy cho bảng Pilot.
- Teacher key so sánh constant-time.

## Kiểm thử local
1. Chạy SQL migration.
2. Tạo `.env.local`.
3. Restart `npm run dev`.
4. `/cloud-activation` phải hiện 3 READY.
5. `/teacher-cloud`: kích hoạt 1 hồ sơ, ghi lại mã học sinh.
6. `/cloud-sync`: pull hồ sơ bằng mã lớp + mã học sinh.
7. Học một bài rồi push lại Cloud.
8. `/teacher-cloud`: refresh và xác nhận `updatedAt` thay đổi.
