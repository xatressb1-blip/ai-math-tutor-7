# AI Math Tutor v2.7.0-beta.1 – Real 10-Student Pilot Operations

## Mục tiêu
Chuyển từ “Cloud chạy được” sang “giáo viên có thể vận hành một buổi Pilot 10 học sinh”.

## Route mới
- `/pilot-onboarding`
- `/pilot-ops`

## Pilot Onboarding
Học sinh chỉ cần:
1. Mã lớp.
2. Mã HS.
3. Bấm mở hồ sơ.
4. Student Brain được Pull trước khi vào Student Home.

## Teacher Pilot Control Center
- 0–10 học sinh.
- Tình trạng sync.
- Mastery/Accuracy.
- Active mistakes.
- Cảnh báo HS cần chú ý.
- Export CSV.
- Backup JSON.
- Checklist trước/trong/sau Pilot.

## Không thay đổi
- Không migration SQL.
- Không thêm package.
- Không đổi Student Brain schema.
- Không đổi cơ chế conflict protection v2.6.3.

## Kiểm thử
1. `npm run build`
2. `/cloud-activation` = 3 READY.
3. `/pilot-onboarding` Pull được Học Sinh Demo và mở Student Home.
4. `/pilot-ops` nhập Teacher Key → tải đúng Cloud Roster.
5. Test export CSV.
6. Test Backup JSON.
7. Tick checklist, refresh, xác nhận checklist còn.
8. Kiểm tra mobile `/pilot-onboarding`.
