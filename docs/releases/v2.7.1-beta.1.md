# AI Math Tutor v2.7.1-beta.1 – Vietnamese Student UX & Navigation Cleanup

## Mục tiêu
Làm giao diện dễ hiểu hơn với học sinh lớp 7 trước khi Pilot thật.

## Thay đổi chính
- Tiêu đề chính: Học Toán 7.
- 3 hành động chính: Trang học của em / Tiếp tục học / Tiến độ học tập.
- Nhóm HỌC TẬP:
  - Thư viện bài học
  - Phòng học Hình học
  - Luyện tư duy
  - Thi thử
  - Kết quả học tập
  - Mức độ thành thạo
- Nhóm TÀI KHOẢN HỌC TẬP:
  - Bắt đầu học
  - Đồng bộ bài học
- CÔNG CỤ GIÁO VIÊN mặc định thu gọn.
- Typography chuyển sang sans-serif dễ đọc tiếng Việt.

## An toàn
Release này không thay đổi:
- Student Brain
- Supabase
- Cloud API
- Safe Cloud Sync
- Conflict Protection
- Pilot schema

## Kiểm thử
1. `npm run build`
2. `npm run dev`
3. Kiểm tra trang chủ desktop.
4. Kiểm tra mobile.
5. Mở/đóng Công cụ giáo viên.
6. Kiểm tra các liên kết Học tập.
7. Kiểm tra `/cloud-activation` vẫn 3 READY.
8. Pull/Push Học Sinh Demo một vòng để xác nhận không ảnh hưởng Cloud.
