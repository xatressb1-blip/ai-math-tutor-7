# v2.8.3-beta.1 – Vietnamese UX & Guided Workflow

Baseline: `v2.8.2 / d0e1ad8`.

## Mục tiêu
Làm giao diện chuyên nghiệp hơn, giúp học sinh biết bắt đầu từ đâu và giúp giáo viên quản lý theo đúng quy trình sư phạm.

## Luồng học sinh
1. Kiểm tra đúng hồ sơ.
2. Đánh giá đầu vào.
3. Học bài chính → luyện tập thích ứng → luyện suy luận.
4. Xem mức độ thành thạo và tiến độ.
5. Tiếp tục nhiệm vụ AI đề xuất.

## Luồng giáo viên
1. Chọn đúng học sinh.
2. Xem học sinh cần hỗ trợ.
3. Giao hoạt động đúng kỹ năng.
4. Kiểm tra lại tiến bộ và lỗi cần khắc phục.

## Việt hóa chính
- Student Brain → Hồ sơ học tập AI
- Mastery → Mức độ thành thạo / Thành thạo
- Confidence → Mức tự tin
- Accuracy → Độ chính xác
- Reasoning → Luyện suy luận / Suy luận
- Cloud Sync → Đồng bộ dữ liệu
- Teacher Dashboard → Bảng điều khiển giáo viên
- Pilot Roster → Danh sách học sinh
- Pilot Operations → Trung tâm vận hành thử nghiệm
- Readiness → Mức độ sẵn sàng
- Mistakes → Lỗi cần khắc phục
